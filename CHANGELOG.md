# Changelog

All notable changes to cursor-light.nvim will be documented in this file.

## [1.0.0] - 2025-11-26

### Added
- Initial release of cursor-light.nvim theme
- Beautiful light color scheme inspired by Cursor IDE
- Custom statuscolumn with centered line numbers and vertical separator
- LSP Saga integration with themed breadcrumbs
- nvim-tree integration with proper styling
- Full Treesitter and LSP semantic token support
- Comprehensive syntax highlighting
- Configurable UI and integration options
- Documentation and installation guide

### Features
- Clean white background (#FCFCFC) optimized for readability
- Carefully selected color palette for syntax elements
- Custom line number column with separator line
- Git diff and diagnostic colors
- Support for all major languages and file types

### Integrations
- lspsaga.nvim - Themed breadcrumbs and winbar
- nvim-tree.lua - File explorer styling
- nvim-treesitter - Enhanced syntax highlighting
- Native LSP - Semantic token highlighting
